# Referências Bibliográficas

Repositório de catalogação bibliográfica transversal: mantém um catálogo temático de referências acadêmicas e fichas analíticas individuais, com os documentos originais (PDFs) mantidos no Google Drive.

## Onde encontrar cada coisa

- **Catálogo mestre** — [`Referência Bibliográfica - Drive/README.md`](Referência%20Bibliográfica%20-%20Drive/README.md): índice temático, resumos, aderência ao projeto e links para as fontes originais.
- **Situação das fichas** — [`Referência Bibliográfica - Drive/STATUS_FICHAS.md`](Referência%20Bibliográfica%20-%20Drive/STATUS_FICHAS.md): estado consolidado da produção/publicação das fichas (184 fichas individuais publicadas, 0 pendentes, em 26/07/2026).
- **Fichas individuais** — [`Referência Bibliográfica - Drive/fichas/`](Referência%20Bibliográfica%20-%20Drive/fichas/): análise detalhada de cada referência (citações, páginas, resumo analítico).

## Importante

Os PDFs e originais permanecem no Google Drive; este repositório funciona como catálogo e camada de organização bibliográfica, não como repositório dos arquivos originais. Antes de citar método, resultado, número ou conclusão específica de qualquer referência, confirme a informação na fonte original.
